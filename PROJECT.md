# IS218 Assessment Project

Name: Khadija Maxammad Amin

## Purpose

This project is my IS218 assessment assignment. It uses Python and pytest to implement and test addition and subtraction functions.

## Setup

Create the virtual environment:

python3 -m venv .venv

Activate the virtual environment:

source .venv/bin/activate

Install the requirements:

python -m pip install -r requirements.txt

## Testing

Run the student tests:

python -m pytest

Run the student tests and supplied acceptance checks:

python -m pytest tests checks -v

## Test Explanation

For the addition test, the inputs are 2 and 3. The expected result is 5. The assertion checks that add(2, 3) returns 5.
